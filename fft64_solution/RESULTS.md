# 本轮解题结果

已将已有方案迁移到新题面和新接口，并完成完整本机复测。选择迭代 R2、精确 parity banking、数据少保留 1 个小数位、twiddle fraction 9；完整面积 **2236.47 µm²**，相对较小准确基线下降 **37.32%**。新的留出测试最低逐帧 SQNR 为 **55.24 dB**，满足 50 dB 要求。

这不是一次新的 agent 从零 rollout，也不是全局最优搜索。结果来自 ASAP7 RVT/TT、Yosys/ABC/OpenSTA 的 pre-layout 流程；VCS/DC/PrimeTime 和 P&R 尚未运行。

## 选择理由

1. 当前服务档允许复用一个 Butterfly，迭代式准确基线比 SDF 面积小；SDF 首输出更早，但两者都满足截止时间。
2. 精确 parity banking 减少存储读写选择逻辑，节省 23.98% 整体面积。它保持算术语义，收益不归给近似。
3. 数据/系数量化在 banking 基础上再省 17.54%，质量仍有余量。数据内部保留 14 fractional bits、存储宽度 21 bit；输出恢复原有增益；twiddle 为 signed 11 bit /2^9；非平凡旋转采用完整乘积及累加保护位后 RNE，平凡旋转精确旁路。
4. 增加 BF 流水切分改善时序余量，却增加面积和周期延迟。固定 10 ns 目标已满足，因此不选它；不宣称流水减少组合延迟就提高了规定服务吞吐。
5. 再多去掉一个数据小数位的候选在合法低 RMS 复数输入上失败，因此拒绝，没有降低质量阈值。

## 对新 benchmark 的结论

题目可以形成一个小而完整的工程闭环：架构选择 → 精确资源优化 → 量化 → 协议/数值 → 映射/STA → 网表复测。最终方案确实超过拟定的 20% 面积节省目标，但该通过目标仍需真实 DC/PT 平台校准。

新的连续分数是面积相对节省，因此本机为 0.373174；它不沿用旧任务的满分曲线。实际 agent 评分须使用商业平台的面积参考。
