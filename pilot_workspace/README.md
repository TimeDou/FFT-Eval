# Pilot workspace evidence

This archive preserves the completed development process before the Agent workspace is reset. The branch retains the original benchmark and score. `capture_manifest.json` lists retained files and explicitly excluded rebuildable products. Large text reports are gzip-compressed with decompression SHA-256 checks. Final hidden measurements and observed FFT outputs remain in `agent_evaluation/`. This is a compact research record, rather than a byte-for-byte container or disk image.
