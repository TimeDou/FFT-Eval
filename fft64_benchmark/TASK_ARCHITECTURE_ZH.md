# 架构综合评分模式——任务补充

FFT64-Quant 的[中文主任务](TASK_ZH.md)默认使用 `architecture` 评分。本文件仅作为简短索引，**不是另一套不同规格的任务**。

必选可行性包括逐非零帧 SQNR ≥50 dB、正确 FFT/协议/复位、II=384 的最低服务能力、10 ns 时序和映射网表一致性。符合规格但硬件质量分数为 0 的设计也算完成。

连续评分：完整面积 **60%**，已验证有效吞吐率 **30%**，实测最大首输出延迟 **10%**。所有整数 II=64–384 都使用至少 1,024 连续 RTL 帧测试；对最短通过的 II 另做代表性映射网表验证。`design_config.json` 中的 II 仅为提示，不决定得分。

精确评分公式见 [SCORING.md](SCORING.md)，公开/隐藏测试规模与流程见 [EVALUATION.md](EVALUATION.md)。
