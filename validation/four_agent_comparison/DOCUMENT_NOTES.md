# 阅读作者记录时需要修正或限定的表述

这些原始记录保留了 Agent 当时的解释，并不代表每一句都已被本次核验背书。报告中的最终数据以独立隐藏验证为准，中间值按用户授权采信自测。

1. DS-Flash 记录中的 264816 个 quality frames 包含多个 II 的重复测试累计，不是 264816 个独立随机输入帧。公开独立随机规模为 1024，隐藏为 8192，各另加 192 定向帧。
2. DS-Flash 的“20-bit Q13 溢出”解释与保存生成器不一致。生成器在该试验实际保留低 20 位、仍按 Q15 解释，范围约 ±16；正确的 20-bit Q13 范围约 ±64。详见静态检查 JSON 和 STRATEGY_COMPARISON.md。最终 22-bit 候选正常通过，不把失败试验归入最终缺陷。
3. Codex 6.1 记录中某些 timing-high-effort 参数被该 DC 忽略，因此分析应使用实际 clock steering 和导出网表结果，而非把 flag 名称当作效果证明。
4. Codex 6.2 的解析 50.93 dB 误差推导是作者分析，本次只完成经验数值/协议/STA 核验，没有完成相应 formal proof。
5. Opus 关于 112 个 delay words、流水下界、全部合法输入无溢出和未实现架构盈亏点的陈述，是其设计依据，不是本次独立验证给出的全局下界或最优性证明。
6. 开发脚本的面积和 period estimate、quick screen、完整公开评分、独立隐藏最终评分是不同证据。保留未通过和未完整资格点，但不把它们混入最终 feasible 排名。
7. 四次用时和停止方式不一致，每模型只有一次运行；本批可以比较实际交付电路和观察探索行为，不能据此给出等预算的模型总体能力结论。
